# 一键演示操作指南

## 启动

在 Warp 中执行：

```sh
cd <repo>
./scripts/start-local-postgres.sh
npm start
```

如果端口被占用，可指定新端口：

```sh
PORT=8767 npm start
```

然后打开终端显示的本地地址。

## 演示

1. 点击顶部 **开始演示向导**；
2. 点击向导底部 **一键准备并从头开始**；
3. 按 **下一步** 前进；
4. 向导会自动切换到正确角色；
5. 遇到高亮的琥珀色按钮时点击它；
6. 第 10 步的拒绝是预期结果，不是系统故障；
7. 第 12 步用监管/审计视图收口。

如果演示中途操作错了，重新点击 **一键准备并从头开始**。该操作只重置固定合成演示产品，
并在数据库事务内完成；非 Sandbox 租户、其他产品或生产身份模式会被拒绝。
